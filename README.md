## 👩‍💻 About Me

I’m an aspiring **DevOps & Cloud Engineer** passionate about building reliable, scalable, and automated infrastructure.

Rather than simply developing applications, I enjoy designing the systems that power them—from containerization and CI/CD pipelines to cloud deployments and infrastructure automation.

I believe the best way to learn DevOps is by building real-world projects instead of endlessly following tutorials. Every project helps me understand how modern production systems are deployed, monitored, and maintained.

Alongside DevOps, I also have experience with **Python**, giving me a broader understanding of the complete software development lifecycle.

- 🔄 CI/CD Pipelines with GitHub Actions & Jenkins
- 🏗️ Infrastructure as Code using Terraform
